## 两条主要待验证命题

1. M 仅利用真实可用模态与缺失标识，局部补偿能改善缺失条件下目标响应与定位；信息合法的单模型推理仍然成立。
2. M 在训练标签下确实优于 C 的样本上，反馈判别响应可以改善完整输入能力，同时保留完整任务监督；效果不能只来自增加参数或两次前向。

三个候选组成部分是“缺失感知的任务补偿”“完整到缺失的任务响应指导”“可靠缺失到完整的选择性反馈”。均有已有近邻，模块命名不能当作创新证明。由训练集与开发集诊断发现本项目特有问题，再确定是否需要新的内容、位置或可靠性判据。

## 最小实现

共享一个 baseline，两种输入各一次前向。C 使用完整配对输入，M 使用模态可用标识和训练期局部 token mask。先在保持模态/token 索引的位置，仅修改被遮盖位置；补偿模块输入只有 M 的可用特征及标识。禁止把 C 的激活值送入 M；detach 不能消除前向信息泄漏。

首版采用一个小型残差模块，输出层零初始化，完整可用位置增量严格为零。C→M 先只匹配目标响应分布。M→C 在 `loss_M.detach()+delta < loss_C.detach()` 时允许反向目标响应监督，两方向教师目标均停止梯度。保留两路真实标签任务损失。

整模态被mask时，当前补偿覆盖该模态全部token，属于潜在特征补偿；尚未实现“只恢复少量必要任务token”的选择机制，也没有证明恢复了真实完整特征。任务监督不能自动证明这两项更强的表述。

首版不加入实际双向特征交换、深浅层连接、第二轮前向或额外网络。真实部署双缺失沿用公共 IPL 的上一框保持，所有帧计入正式指标；该行为不构成修复能力。

## 数据与训练冻结项

- LasHeR 官方 train882 / val97 开发划分；test245 不进入训练、超参数选择或可靠性学习。
- 从同一 epoch20 严格加载；seed2027 首轮固定，不挑选失败种子。
- 保留 baseline 图像处理、GIoU×2、L1×5、focal×1、AdamW；新增损失先从小权重开始，具体值随运行配置归档。
- 先真实 GPU 单步、梯度有限、优化器更新、保存严格重载、无教师推理、关闭新增机制的 baseline 等价检查，再决定正式预算。
- 使用 GPU2、3；先测每步时间和显存，再记录每轮步数、有效 batch、累积、前向视图数和预计完成时间。不以 smoke 或局部序列代替完整评估。
- 训练失败直接留下原始错误，不采用原 actor 的 GIoU 异常转零或原 trainer 的静默恢复作为新入口逻辑。

## 顺序与解释

| 实验 | 设置 | 主要证据 |
|---|---|---|
| E0 | 原始 epoch20 | 完整、两项 Miss 的同协议基线 |
| E1 | 单路 mask 训练 | 见过缺失条件的收益 |
| E2 | 两路共享参数，各任务损失 | 两种视图及计算预算的收益 |
| E3 | E2+C→M | 单向任务知识的贡献 |
| E4 | E3+局部补偿 | 补偿是否优于蒸馏与等参数投影 |
| E5 | E4+选择性 M→C | 完整能力与缺失能力能否同时改善 |

开发集先做递进对照，训练量/视图数匹配。只有最终冻结候选做完整测试及多种子确认；小幅变化不能据单次运行宣称机制成立。若反向反馈没有完整性能提升，则拒绝“反哺完整分支”命题；若普通投影相同，则拒绝“修复特征的特殊价值”命题。

主文证据只保留五组：完整与缺失主结果；补偿及等参数对照；单/双向知识传递；信息与推理成本约束；失败分析。修复前/后反馈、特征重建与任务监督差异列入有辨识力的后续消融。跨层 E6 在 E5 成立后再做。

## 评估和成本

固定官方 JSON masks；第一帧完整初始化；baseline 单缺失复制可用模态，双缺失保持。新模型必须明确传入真实可用标识，并记录模板更新可用性，不能把复制得到的图像当作另一传感器的真实观测。完整 E0、新模型、所有消融均用相同 GT 与 rgbt toolkit，479 序列全覆盖，不丢弃失败或双缺失帧。

报告参数增量、训练两次前向成本、推理单次前向耗时和显存。E0 续跑阶段 2561.43 秒约42.7分钟，另有初始双 worker 阶段；不是总墙钟时间。新方法时间由实际速度估计，不能直接承诺相同耗时。
