# 模块A隔离实现约束

本分支基于BN准备提交`71f46ebeedf1e80c992f34ce811795f8cd56ac7f`。只准备实现及机械检查，不合入活动项目，不启动正式训练；先完成当前归因和BN对照，再确定稳定控制U。A是否有效必须由完整训练、四套全量指标及选择策略对照证明。

## 前向与选择

- 仍使用共享CADTrack baseline，在第6个block后插入一个补偿模块；不增加完整分支到缺失前向的激活连接，不移动插入点或改变预测头。
- 模块只读取该视图自身的RGB/TIR token、availability及初始模板。初始模板的中心区域减外部区域池化形成目标线索代理；它不是已认证的身份表示。
- 首版只修改搜索token，模板和CLS不直接写入残差。先将16×16搜索网格分成4×4个区域，每区16个token；默认选择4区、64个token。此预算是未选参的开发初值，不是Test最优配置。
- 对每个区域预测有符号任务效用。utility模式按效用选K区；similarity、random同K和all使用同一补偿器作对照。random有独立、可保存/重置的随机状态，不消耗数据和mask的全局RNG；评测在每条序列初始化时重置。
- 只有选中的token进入残差MLP。选择器和主干仍稠密计算，不能把它称为整网稀疏推理。
- 缺失模态允许补偿；可用模态也允许残差系数受限的细化。该系数不约束残差向量本身的绝对范数，不能保证完整性能不降。残差输出零初始化，保证初始化前向恒等。默认已观测细化系数上限0.1，宽度128、内部深度1；都是待开发验证的内部参数。

## 效用监督

- selector不能仅以模板相似度为标签。训练在预定microstep采样一个视图、一个搜索帧和每个样本的一个区域，测该区域补偿开/关时的原生定位损失。
- 两种反事实共享第6层前的同一token状态、参数和后半段随机状态；目标侧断梯度，必须固定全部BN运行统计。探针不能改变主任务的RNG状态或BN缓冲。
- 标签为`clip((L_off-L_on)/max(L_off,1e-6),-1,1)`，用SmoothL1回归该区域的效用。标签有正负，零初始化时可能全为零；不能人工翻转符号或凑出有益样本。
- 选择器读取断梯度的区域上下文，辅助损失的直接梯度只进入选择器；补偿器、归一化和共享主干的直接梯度来自原任务/KD。全局梯度裁剪仍可能因选择器梯度改变而间接改变其他参数的步幅，不能声称实际更新完全隔离。反事实输出不反传，不将易预测效用额外作为主干目标。
- 该标签只表示当前模型、单一区域、同一裁剪的任务损失变化，不保证K区域联合有益，不证明真实特征重建、身份正确或闭环恢复。
- Complete/Missing交替获得探针；探针帧轮转，区域来自单独的CPU Generator。默认每4个microstep一次，记录实际探针数、视图、帧、区域及开/关损失。额外后半段前向和训练时间单独披露，同epoch不等同计算预算。
- 原C/M任务损失、正向响应KD保持独立；本分支不实现模块B/C或声称反向反馈有效。

## 检查与正式实验边界

需要检查初始化恒等、只修改所选搜索位置、已观测细化路径、残差MLP实际token数量、效用标签方向与detach、独立RNG及严格重载；再用原E0和真实训练数据验证一次AdamW更新及无教师推理。CPU机械检查不等于GPU检查或完整实验。

正式候选仍从同一原E0独立开始，完整20轮/50000更新、固定最终epoch20，并覆盖LasHeR/RGBT234完整和Miss全部序列。选择模式的对照使用相同训练量、监督与参数；all的补偿位置数和计算不同，必须披露。内部宽度、深度、K和细化上限允许按数据集开发选择，同一数据集完整/Miss固定相同配置和权重。当前Test已参与失效分析，不据此选这些参数。

相对于旧E4，本模块还改变模板写入位置、目标条件化及可用位置细化，不能把A−E4全部解释为效用选择贡献；同一A模块内的all/random/similarity/utility对照用于归因。旧R与新A不同时叠加。
