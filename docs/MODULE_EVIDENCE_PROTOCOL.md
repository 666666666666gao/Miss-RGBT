# 三个组件需要的证据

当前三个组件均未证明有效；20轮E3/E4仍排在已有首轮后。以下验收不改变当前模型、配置、固定末轮或测试协议。

| 候选组件 | 具体问题与传递内容 | 最小有效性对照 | 不能替代的证据 |
|---|---|---|---|
| 缺失感知局部任务补偿 | 根据真实可用模态和模板可用标识，补偿被mask的位置；检查目标响应和定位 | 同预算E4−E3；另与同参数量普通投影比较 | 参数增加、重建误差、非零残差不能证明任务增益或恢复真实特征 |
| 完整→缺失响应指导 | 完整路径提供空间目标响应分布；缺失前向独立，不复制教师激活值 | 同预算E3−E2，两路task/视图数相同 | E3−原始E0不能排除额外训练、显式缺失标识或两路task贡献 |
| 可靠缺失→完整反馈 | 标签下M更可靠的任务响应反馈给C，保留完整task；目标和可靠gate停梯度 | 同预算E5−E4，另比较无筛选反馈 | 可靠比例、KL非零不证明参数更新或完整能力改善 |

所有候选都需全量完整/Miss指标。对选择性反馈，至少检查完整LasHeR/RGBT234是否改善，以及缺失条件是否达标；若只改善Miss，不能声称反哺完整路径已成立。完整输入保留任务监督是设计约束，不能代替完整能力实测。

若进一步主张“改善C对非优势模态的利用”，在val97中固定同一模板/搜索裁剪和帧，分别测完整、删RGB、删TIR的目标响应/定位损失，比较增加该模态带来的边际任务收益。不同状态的Test帧分组不能替代这个对照；单独提高完整PR也不能证明保留了模态特有信息。反馈内容应落实为可靠目标响应和目标—背景区分，不扩展成全部特征逐维相同。

## 已有实际诊断如何约束后续设计

[E0同帧报告](../reports/e0_paired_diagnostics_v1/README.md)确认首次缺失前53027帧bbox完全一致；发生缺失后的当前完整帧存在持续差距。其[搜索区域统计](../reports/e0_paired_diagnostics_v1/search_support.json)还显示，LasHeR恢复帧有5536/54822（10.0981%）完整轨迹crop与GT相交而缺失轨迹crop完全错开。因而先检查修复是否在有效目标支持区域内，不能默认每次局部token修复都能看到目标。

这个诊断来自Test，只用于描述已冻结baseline的失败现象，不调整当前E3/E4或按Test选epoch。若据此引入历史/模板干预，先在train882/val97进行同帧对照，固定真实可用信息，再分别控制上一预测裁剪与模板更新。GT裁剪或重置只能标为诊断上界，不能加入部署或主结果。

原生`vit_care.Block.forward`两模态复用同一attention/MLP，原始C/D没有进入本次forward；当前R还增加了两模态之间的中间交互。因此E4收益需要排除普通交互/增加容量的解释。不能直接复制分割论文“只更新弱模态encoder”的策略并声称RGB参数保持不变。

## E5启动前必须检查的真实梯度

1. 使用预先固定训练样本/seed和正常mask，记录是否有真实`loss_M+0.1<loss_C`样本；不人工翻转gate凑通过。若当前固定检查无可靠样本，只能记录没有触发。
2. 将反向项与其余task/正向KD分开观察梯度贡献，确认M目标断梯度、C接收端有有限非零梯度；同一AdamW确实包含接收参数。
3. 当前C全可用时R被零门控，反向项不更新修复器，进入共享baseline。冻结所有baseline、只保留R，会让该方向没有有效受体。共享参数更新也会影响下一次M；detach不等于保护另一视图参数。
4. 真正执行非零反向项的更新、保存和严格重载；与reverse_weight=0的同输入控制比较参数变化。先证明实现，再用完整训练与指标判断收益。

原生探针已准备在 [`analysis/validate_reverse_feedback.py`](../analysis/validate_reverse_feedback.py)，当前只通过 Python3.7 语法检查，**尚未执行 GPU/真实数据检查，不能称为反向反馈通过**。它读取既有训练后 E4 checkpoint，固定 seed 和最多八个 train batch，保留实际可靠性门；没有样本触发时明确记录未触发。触发后检查 M 响应目标无梯度、C 响应有梯度、反向参数梯度只进入共享 baseline，并与零反向项比较同一原生 AdamW 状态的一次更新及严格重载。更新仅使用一个 microbatch，是方向和优化器实现检查，不能替代有效 batch8 的正式训练或性能实验。

全局梯度裁剪还可能间接改变修复模块的更新幅度：反向项使共享 baseline 梯度改变，整体范数与统一裁剪系数也可能变化。因此应分别报告“R 的直接反向梯度为零”和“R 相对零反向项的实际更新差异”，不能要求后者必然为零。探针不加入当前训练/排队流程；待当前冻结实验完成且 GPU 空闲时运行，不占用正在训练的 GPU。

从服务器项目根目录执行，输出目录必须是新的审计目录：

```bash
CUDA_VISIBLE_DEVICES=2 PYTHONPATH=. conda-envs/miss_rgbt/bin/python analysis/validate_reverse_feedback.py \
  --checkpoint checkpoints/e4_full20_seed2027/epoch20.pth.tar \
  --output reports/native_reverse_probe_e4_full20_seed2027
```

上述检查是针对现有native反向可靠比例为0和外部反馈脚本optimizer受体错误的具体证据，不能跳过后用loss日志代替。外部核查见[SDSTrack/SMML/RobustSeg源码记录](OPEN_SOURCE_FINDINGS_20261013.md)。

## 训练量与信息约束

E2/E3/E4/E5固定同初始epoch20、20×20000采样样本、有效batch8、50000更新、seed2027、两视图/相同预处理，使用固定最终epoch20。显式mask的未训练推理控制，以及仅完整输入继续训练的控制，都需与原始E0分开标记。三项有效消融、同参数对照、推理成本与完整能力保护齐备前，不认定三个论文贡献成立。
