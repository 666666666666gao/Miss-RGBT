# 最终20轮：定位质量与恢复帧的离线诊断

使用E0及固定最终epoch20的E3/E4真实完整/Miss轨迹。仅CPU计算，未运行模型、读取新进度或改变训练、阈值、权重。所有统计是描述性分析，不证明修复或BN的因果效果。当前完整指标与严格目标结论保持不变。

## 统计口径

框诊断排除首帧及该参考GT任意坐标非正的帧，使用未四舍五入的连续xywh；按帧汇总。RGBT234分别使用固定visible/infrared GT，不在两种GT间为宽高选择更有利答案。中心命中定义为欧氏误差≤20像素。宽/高MAPE为abs(pred/GT−1)的均值×100。mean IoU与当前评分包21阈值、序列等权的SR/MSR是不同量，不能替换主指标。

各自命中帧统计的样本集合随模型改变，因此另报告同一批共同命中帧。几何搜索区域采用冻结factor4及原sample_target取整公式；排除双缺失保持帧，要求两种GT都有效，并允许任一GT与crop相交。相交不保证目标像素可见或身份可靠。Test已参与失败诊断，后续参数只由独立开发数据确定。

## 观察、解释边界与下一步

1. RGBT234-Miss visible_GT下，各自命中IoU由69.715816%降至69.406985%，但共同命中的93350帧为70.097636%→70.207156%。因此各自命中均值下降不能单独证明E4框回归变差；MSR仍需按原序列口径评价。后续验证同时保留固定共同帧及序列等权汇总。
2. E3在LasHeR恢复帧的“完整有而Miss无crop相交”由E0的10.098136%降至4.861187%，但Miss绝对无相交率由17.514866%升至18.364890%。相对完整路径的缺口变小，可能与完整路径本身退化并存；不能只凭缺口缩小说鲁棒性增强。后续B需同时报告绝对失败和配对损失。
3. E4恢复帧Miss无相交率为LasHeR16.269016%、RGBT2344.686373%；E0分别17.514866%、4.656016%。当前状态恢复问题仍存在，改善有数据集差异。几何统计不证明扩域模块一定有效；B需独立训练/闭环评估及扩域、身份核验控制。
4. 同一MSR曲线按序列与帧加权会给出不同方向；较短两个长度分组平均下降、较长两组平均上升，这是当前模型的描述性相关，不证明序列长度导致收益。保留原序列等权成绩，并在val上检查补偿效用是否跨序列成立。

当前归因队列及14:10:39诊断节点保持不变。本诊断没有运行A/B/C、完成E0-FT/E2训练或证明三个论文贡献成立。
